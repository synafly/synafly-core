# Context: the "immortal fruit fly" idea

A [BlockBeats report](https://www.theblockbeats.info/flash/367136) dated September
14/15, 2026 discusses the idea of "immortal fruit flies" on BNB Chain: preserving
model state and interaction history for later restoration. This is a motivating
concept, not evidence that SynaFly is endorsed by any quoted person or that a
biological individual has become immortal. Token-price movements are not research
evidence.

## What the neuroscience reference does and does not show

[Eon's technical article](https://eon.systems/updates/embodied-brain-emulation)
describes integrating connectome-constrained brain models with a simulated body
and sensory/motor interfaces. It explicitly characterizes the system as work in
progress and discusses modeling limitations and existing motor controllers.
SynaFly does not reproduce that system. No Eon, FlyWire or NeuroMechFly code was
copied into this research implementation. We use an independently written toy
integer model on an excerpt of the separately licensed MaleCNS weight dataset.

## Operational meaning here

"Continuity" means the same specified digital state can be resumed from retained
checkpoint and input data on another keeper. It does not establish consciousness,
preservation of a biological individual's identity, learned memory transfer,
whole-brain emulation or guaranteed perpetual availability.

A state hash proves a commitment to bytes. It is not the bytes themselves, a
backup, a scientific validation certificate or a proof that the model is alive.
Learning and plasticity are absent from the current model; interaction history
here is a deterministic stimulus log, not an autobiographical memory claim.

## Release boundaries

This is a partial, standalone research release. The live browser experience at
[synafly.fyi](https://synafly.fyi/) is a different system. Do not describe the whole
production product as open source solely because this repository is public.
The v0.2 release adds a bounded RPC edge and controlled comparisons, not a
biological RPC network. Future releases may add verified model adapters,
independently operated keepers, public BSC checkpoints and broader relay
experiments. Their implementation and evidence must precede completion claims.
